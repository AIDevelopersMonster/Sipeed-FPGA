# LAB-20.6 — первая собственная программа RISC-V на Tang Nano 20K

[Главная страница](../README.md) · **[Как повторить на Windows по шагам](../REPRODUCE_LAB20_6_RU.md)**

**HARDWARE PASS — 2026-11-08.** Создана программа на ассемблере RV32I+Zicsr. Бинарник размером **740 байт**, включая код, строки и таблицу меток, записан в SDRAM **`0x40010000`**, считан обратно **740/740 байт** и реально запущен процессором **VexRiscv_Min**. Получен полный UART-отчёт.

**Зачем:** проверить, что диагностическая печать способна менять состояние UART FIFO, которое она же измеряет. Собственная программа сначала снимает состояние без вывода, затем пишет заголовок и снимает состояние повторно. Результат **`TXEMPTY=1` до вывода → `TXEMPTY_AFTER_PRINT=0` после**.

## Главное правило запуска

Программа работает **из временной SDRAM**, заводскую FPGA Flash не изменяет. До запуска должен быть **PASS обратного чтения всех 740 байт**. После `boot 0x40010000` программа остаётся в цикле HOLD: вернуться к заводскому BIOS можно кнопкой **RESET**.
