# LAB-20.4 — ROM Explorer: читаем и разбираем заводской BIOS

[Главная страница платы](../README.md) · **[BIOS / LiteX — подробный справочник](../BIOS/LiteX/README.md)** · [LAB-20.5 UART и CSR](../05-UART-CSR/README.md)

Через LiteX BIOS мы считали **128 КиБ адресного ROM-окна**, обнаружили четыре **совпадающих 32-КиБ периода** и сохранили уникальный 32-КиБ образ. Это не означает, что физическая конфигурация после синтеза непременно содержит четыре независимых блока ROM.

**[Запустить ROM Explorer v3.3](index.html)** — автономный HTML со встроенным BIOS-образом: можно смотреть инструкции RISC-V, регистры, память, UART/CSR и шаги исполнения. **Это программная модель, не настоящая временная трасса CPU.**

- **[Проверенный бинарный ROM, 32 КиБ](PiKoSoL_LAB20_ROM_32KiB.bin)** — SHA-256 `3347be74e9716744949e572229345c3ea9e74f1740001408b934c0d85c79c5bc`.
- [Манифест](PiKoSoL_ROM_32KiB_manifest.json) · [проверка совпадения алиасов адреса](ROM_ALIAS_AUDIT.md).
- [Скрипт извлечения 32 КиБ из исходного 128-КиБ дампа](PiKoSoL_LAB20_reduce_rom_32KiB.ps1) — нужен оригинальный дамп, не входит в текущий пакет.
- [Тест встроенного ROM и CRC](test_v32.js).
