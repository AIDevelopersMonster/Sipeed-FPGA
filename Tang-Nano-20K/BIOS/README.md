# BIOS на FPGA: каталог для Tang Nano 20K

[На главную Tang Nano 20K](../README.md)

**BIOS** здесь — начальная программа, которую процессор исполняет после сброса FPGA-системы: инициализация UART/памяти, поиск источника загрузки и интерактивный монитор. BIOS не равен конфигурационному файлу FPGA (`.fs`) и не равен нашему пользовательскому `snapshot.bin`.

## Доступная реализация

**[LiteX BIOS — подробный справочник, команды, исходный ROM и HTML-эмулятор](LiteX/README.md)**.

В нашей Tang Nano 20K заводская FPGA-конфигурация содержит процессор **VexRiscv_Min**, систему LiteX и ROM с BIOS от **13 марта 2023 года**. Через COM25 (на нашем испытательном ПК, 115200 8N1) получено приглашение `litex>`. Мы прочитали ROM, исследовали UART и выполнили собственный RISC-V код в SDRAM без записи конфигурационной Flash.

На **Tang Nano 9K** используется собственный PiKoSoL/PicoRV32, а не эта заводская система LiteX. Команды, бинарники и карта памяти двух плат не взаимозаменяемы.
