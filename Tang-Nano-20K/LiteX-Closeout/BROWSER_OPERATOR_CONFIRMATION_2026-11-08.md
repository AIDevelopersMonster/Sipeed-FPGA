# Tang Nano 20K — подтверждение работы браузерного стенда (2026-11-08)

**Объект:** [LiteX 20K — Browser Diagnostic](https://aidevelopersmonster.github.io/Sipeed-FPGA/lab20/closeout/)  
**Источник:** сообщение оператора после рекомендации подключить браузер к COM25 и выполнить `help`, `mem_list`.  
**Оригинальный ответ оператора:** «Работает».

## Статус и границы доказанного

- **`BROWSER_OPERATOR_WORKS`**: пользователь подтвердил работу предложенной браузерной диагностики Tang Nano 20K. Отдельный скриншот или журнал с COM25 не предоставлен.
- **Не подтверждены отдельным документом:** результат каждой команды `help`, `mem_list`, `UART status`; корректная загрузка файла журнала; работа в других браузерах и на других платах.
- Не выдаём программу в браузере за эмуляцию RTL по тактам. Браузерный интерфейс для 20K отдельный от PiKoSoL/Tang Nano 9K.
- Не выполнялись: запись SDRAM, включение IRQ, запуск `boot` или программирование FPGA Flash.

Для расширения статуса до `BROWSER_READONLY_COM_COMMANDS_PASS` необходим текст/экспорт read-only сессии, полученный через кнопку «Сохранить журнал» после `help`, `mem_list` и «Прочитать UART status». Это опциональная проверка, не причина вновь проходить уже подтверждённые BIOS/UART аппаратные тесты.
