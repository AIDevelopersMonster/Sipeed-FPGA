# Tang Nano 20K — примеры использования платы как изделия

[← Главная страница платы](../README.md) · [Состояние и границы работ](../PROJECT_STATE.md)

**Цель этой папки:** пользовательские демонстрации самой Tang Nano 20K, а не дальнейшая детализация исследовательских лабораторий. Активная разработка примеров начинается **после шести закрывающих проверок LiteX**, зафиксированных в [PROJECT_STATE.md](../PROJECT_STATE.md). Ниже — маршрут и конкретные существующие материалы Sipeed для подготовки.

## Классы образов, которые нельзя смешивать

**Независимая FPGA-демонстрация:** готовый битстрим Sipeed для HDMI или аудио заменяет конфигурацию FPGA в SRAM; не следует предполагать, что в нём остался заводской LiteX BIOS или что пользовательская `snapshot.bin` будет исполняться. Это отдельный пример, а не дополнительная команда BIOS.

**Интегрированная демонстрация:** собственная сборка LiteX + VexRiscv + новые периферийные блоки, где HDMI, SD, кнопки и программа работают в **одном FPGA-образе**. Это существенно более сложная работа, не подтверждённая текущими аппаратными протоколами.

## Условия выпуска каждого EX

1. У пользователя есть **готовый файл для конкретной Tang Nano 20K**, указаны источник, точная версия, размер, SHA-256; для исходников — минимальные команды сборки и назначение ножек.
2. **Только временная загрузка в FPGA SRAM**; заводская Flash не перезаписывается. Перед выбором способа программирования проверены его режим и совместимость платы.
3. Чёткий ожидаемый результат: что именно видно **на HDMI**, на LED или в терминале, что находится **на SD-карте**; где нужен монитор, карта, кабель, COM или управление.
4. Аппаратный протокол со снимком/видео или UART-логом и отметкой `PASS/FAIL`. Тесты модели не выдают за аппаратные.
5. Все файлы доступны по одной странице GitHub, а если требуется браузер — и по реальной ссылке GitHub Pages.

## Предупреждение об источниках

У Sipeed на GitHub действительно опубликованы готовые примеры `hdmi.fs` (~4,6 МБ), `audio.fs` (~7,26 МБ), LED, UART и WS2812. Это **подтверждает доступность исходных материалов**, но не подтверждает работу этих образов **на нашей физической плате**. В исторической сборке LiteX 20K HDMI отсутствует как встроенный блок, а SD подключается опционально во время сборки. Не считать разъёмы автоматически работающими через `litex>`.

**На данный момент нет статуса `EX20 BOARD PASS`.** Следующий прикладной выход после закрытия LiteX — EX20-01 HDMI и EX20-02 органы управления; **не** дополнительная цепочка лабораторий FIFO/IRQ/STA ради самих исследований.


## EX20-01 — оператор подтвердил BOARD PASS 2026-11-09

Проверены на физической плате: показ HDMI, переключение тестового изображения кнопкой и возвращение заводского LiteX BIOS после выключения и включения питания. SRAM-программирование через CLI завершилось exit 0; SHA-256 исходного Sipeed bitstream `cb024d255692321a9b7fa22cf603dd89d1cd7875930ad57e00fd2bccf6cf9b0a`. [Квитанция](EX20-01-HDMI/EX20-01_BOARD_PASS_2026-11-09.md). Это **независимый образ Sipeed**, не интеграция RISC-V с HDMI.
