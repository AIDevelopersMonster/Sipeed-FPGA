# 00 — С чего начинается Tang Nano 20K: заводской LiteX BIOS

[Главная страница Tang Nano 20K](../README.md) · **[Полный справочник BIOS/LiteX](../BIOS/LiteX/README.md)** · [Как повторить первый собственный код](../REPRODUCE_LAB20_6_RU.md)

Плата **Tang Nano 20K (GW2AR-18)** работает с **заводской системой LiteX** на **RISC-V VexRiscv_Min @ 48 МГц**. Система включает ROM с BIOS, UART-монитор и внешнюю SDRAM **8 МиБ**; ранее в BIOS прошёл тест памяти объёмом 2 МиБ.

Мы получали приглашение `litex>` по UART **COM25, 115200 8N1** на испытанном Windows-компьютере. Номер порта на другом ПК может отличаться.

**Исходные подробные измерения, стартовый лог, публикации и таблицы**: [технический отчёт LAB-20](../../docs/lab20/README.md).

Вместо перепрошивки FPGA мы используем заводской BIOS для чтения памяти, а затем для записи небольшой собственной программы в SDRAM и её запуска. Этот эксперимент доказан в [LAB-20.6](../06-RV32-RAM-Diagnostics/README.md).
