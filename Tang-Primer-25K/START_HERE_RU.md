# Tang Primer 25K + Dock — начало работы

## Цель

Создать воспроизводимую лабораторию процессорных архитектур: RISC-V ядра, шины, подсистемы памяти, периферия, измерения CPI и аппаратных ресурсов.

## Комплектация

- Подтверждено пользователем: Tang Primer 25K с Dock-платой.
- По фотографиям комплектов и уточнению пользователя: PMOD LED x2, BTN x1, DIGTUBE x2, TF x1, DVI x1, DVP/OV5640 — пока отсутствует. [Инвентаризация](PMOD/README.md).
- Отдельного PMOD GPIO нет; проверяем GPIO с имеющимися LED/BTN/DIGTUBE.
- Наличие отдельного SDRAM-модуля не подтверждено.
- Не подтверждено: точная ревизия кристалла, подключение UART и JTAG, версия используемого ПО.

## Быстрый практический маршрут

**PMOD → DVI → TF/microSD → USB Host → контроллеры → процессоры → ОС → игры.** [Рабочий план](QUICK_START_PLAN.md).

Никаких обязательных длинных исследований перед первым тестовым изображением или чтением карты. Сначала проверяем готовые примеры Sipeed. Наличие USB-A ещё не подтверждает работу USB Host без проверки RTL и аппаратного подключения.

## Предыдущая процессорная программа (второй этап)

1. **PR25-00 — Board Bring-up:** идентификация, тактирование, безопасная загрузка в SRAM, LED/UART/BRAM, отчёт STA.
2. **PR25-01 — PicoRV32:** перенос проверенных процессорных тестов с Nano 9K, без копирования результатов испытаний.
3. **PR25-02 — VexRiscv:** сравнение при одинаковом окружении и документированных параметрах.
4. **PR25-03 — RV32I Core:** собственное минимальное ядро с тестами ISA и измерениями.

## Статусы

- `NOT TESTED` — испытания не проведены.
- `SIM PASS` — пройдена симуляция.
- `BUILD PASS` — завершилась сборка.
- `STA PASS` — временные ограничения подтверждены.
- `BOARD PASS` — результат подтверждён на реальной плате.

Нельзя выводить BOARD PASS из успешного синтеза или из опыта с другой платой.

## Безопасность

Первоначально использовать только временную конфигурацию FPGA (SRAM). Не стирать заводскую Flash; до записи во Flash нужен документированный способ восстановления.
