# PMOD — Tang Primer 25K + Dock

Каталог аппаратных PMOD-модулей: документация, независимые RTL-контроллеры, тесты и протоколы проверки на реальной плате.

## Инвентаризация

| Модуль | Наличие | Статус |
|---|---|---|
| [TF / microSD](TF/README.md) | **Подтверждено пользователем: имеется** | NOT TESTED on Primer 25K |
| DVI / HDMI | Не подтверждено | CANDIDATE |
| BTN | Не подтверждено | CANDIDATE |
| LED | Не подтверждено | CANDIDATE |
| DIGTUBE | Не подтверждено | CANDIDATE |
| DVP camera / OV5640 | Не подтверждено | CANDIDATE |

Фотографии наборов PMOD не являются подтверждением наличия всех показанных модулей.

## Структура

- `TF/` — первый физически имеющийся модуль; карта microSD через SPI, тесты CMD0/CMD8/ACMD41/CMD58/CMD17 (по согласованному плану).
- Будущие модули: отдельный каталог с паспортом, источниками, pinout и отчётами.

## Правила

- Никаких неподтвержденных назначений FPGA pin/PMOD headers: сначала схема Dock, маркировка и прозвонка при необходимости.
- Проверить уровни напряжения и питание PMOD по документации конкретного модуля.
- Исходники сторонних IP хранить с ссылкой, версией и лицензией; не выдавать за свою разработку.
- Независимые статусы SIM PASS / BUILD PASS / STA PASS / BOARD PASS.
- Исходно только чтение SD. Запись и форматирование запрещены в базовой аппаратной аттестации.
- Только SRAM programming FPGA, не изменять конфигурационную Flash без восстановления.
