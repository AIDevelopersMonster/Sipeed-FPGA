# PMOD — Tang Primer 25K + Dock

Инвентаризация уточнена по фотографиям пользователя: **показанные комплекты имеются**. Отдельного модуля с названием «PMOD GPIO» в комплекте нет и он не требуется: GPIO проверяется модулями LED, BTN и DIGTUBE.

| Оборудование | Количество на фотографиях | Аппаратный тест |
|---|---:|---|
| PMOD DIGTUBE, двухразрядный индикатор | 2 | цифры 00–99 |
| PMOD BTN, кнопки/переключатели | 1 | события нажатий |
| PMOD LED | 2 | бегущий огонь |
| [PMOD TF / microSD](TF/README.md) | 1 | SPI, CMD17, сектор 512 байт |
| PMOD DVI | 1 | тестовое изображение на мониторе |
| PMOD DVP + OV5640, Camera Package | 1 | отдельная последующая проверка камеры |
| Tang Primer 25K + Dock, USB-C | 1 | программирование и USB-A Host |

Сведения основаны на представленных изображениях комплектов и сообщении пользователя о наличии всего показанного. Для подключения использовать схемы конкретных модулей и Dock; электрическая совместимость и работа пока не проверены.

## Сразу проверяем

1. PMOD LED — простое переключение выводов, далее BTN и DIGTUBE.
2. DVI — рабочий тестовый шаблон.
3. TF — SPI microSD read-only.
4. USB-A на Dock — USB Host HID при наличии поддерживаемого RTL.
5. Контроллеры, процессоры RISC-V / Z80, ОС, игры.

Отдельный PMOD GPIO **не покупать и не искать**.

## Требования

Только подтвержденная распиновка и правильное питание; в начале прошивать FPGA в SRAM, не изменять Flash. Статусы SIM / BUILD / STA / BOARD PASS фиксировать только по фактическим результатам.
