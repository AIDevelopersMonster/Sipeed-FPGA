# PR25-PMOD-TF — протокол аппаратной проверки

**Текущий статус:** NOT TESTED. Это план, а не отчёт.

| Шаг | Проверка | Требуемое доказательство |
|---|---|---|
| 00 | Маркировка TF и распиновка Dock | Фото, схема, таблица FPGA pad ↔ PMOD pin |
| 01 | Питание, GND, линии CS/CLK/MOSI/MISO | Проверенная электрическая схема |
| 02 | CMD0/CMD8/ACMD41/CMD58, SPI slow init | UART-лог ответов и таймаутов |
| 03 | CMD17 read-only, 512 bytes | Дамп сектора, CRC16 и hash |
| 04 | Последовательное чтение блоков | Счётчики ошибок/таймаутов |
| 05 | FAT32 read-only | Проверка BPB, FAT, DIR и файла |
| 06 | MMIO из RISC-V | Исходники CPU и воспроизводимый board log |

## Измеряемые параметры

- SPI SCK на инициализации и в рабочем режиме (измеренная частота);
- такты/время на запрос и сектор;
- ошибки R1, время ожидания токена данных, ошибки CRC;
- фактический throughput и расход LUT/FF/BRAM;
- SHA-256 исходного образа тестовой карты и считанных контрольных данных.

## Условия PASS

SIM PASS требует проверенного testbench; BUILD PASS — логов синтеза/P&R; STA PASS — соблюдения ограничений; BOARD PASS — отчёта о реальной плате с версией битстрима, картой, датой и наблюдаемыми результатами.
