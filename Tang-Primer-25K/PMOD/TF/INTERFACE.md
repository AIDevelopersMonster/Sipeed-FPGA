# PMOD TF — интерфейс к SoC (проектный контракт)

Документ описывает **предлагаемый интерфейс**, не готовую RTL-реализацию.

## Physical SPI

Сигналы `spi_cs_n`, `spi_sck`, `spi_mosi`, `spi_miso`. Назначение PMOD-контактов и FPGA pads: TBD после проверки схемы и ревизии.

## Block read API

- `start` + `lba[31:0]` запускает запрос чтения сектора.
- `busy`, `done`, `error` и `error_code` описывают выполнение.
- Буфер 512 байт, адресуется индексом `0..511`.
- Только чтение; запись отключена архитектурно.
- Все междоменные сигналы должны быть синхронизированы или сопровождаться CDC-обоснованием.

## CPU integration

Отдельный MMIO wrapper над контроллером. Базовый адрес и карта регистров — TBD после согласования общей карты памяти PR25 SoC. Не фиксировать адреса, пока не выбран системный интерконнект.

## Tests

Контроллер SPI → команда SD → буфер сектора → MMIO → драйвер RISC-V → FAT32 reader (read-only). Каждая граница имеет независимые тесты.
