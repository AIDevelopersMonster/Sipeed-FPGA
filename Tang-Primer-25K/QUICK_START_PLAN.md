# Tang Primer 25K — быстрый практический запуск

**Имеется:** Primer 25K + Dock, PMOD DIGTUBE x2, BTN x1, LED x2, TF x1, DVI x1, DVP/OV5640 — пока отсутствует (по фотографиям комплектов и подтверждению пользователя). На Dock имеется USB-A. Отдельного PMOD GPIO нет, он не нужен.

| Шаг | Что запускаем | Результат |
|---|---|---|
| 1 | PMOD LED, BTN, DIGTUBE через GPIO платы | Светодиод, кнопки, цифры |
| 2 | PMOD DVI | Картинка на мониторе |
| 3 | PMOD TF / microSD | Прочитан сектор CMD17 |
| 4 | USB-A Dock / USB Host | Обнаружена HID клавиатура, получены события |
| 5 | Контроллеры UART/SPI/таймер/SD/video/USB | Общая периферия SoC |
| 6 | CPU RISC-V и другие HDL ядра | Запуск программы |
| 7 | Монитор / ОС / файловая система | Консоль, файлы, приложения |
| 8 | Игры и демонстрационные программы | Проверка готовой вычислительной системы |


Использовать готовые исходники производителя прежде всего. Проводить минимум проверок, нужных для уверенного результата; не подменять тесты длинными исследованиями.

USB-A как разъём сам по себе не доказывает работоспособность host-контроллера: потребуется соответствующее RTL и тест на плате. Внешняя SDRAM не подтверждена. Программировать сначала только SRAM.
