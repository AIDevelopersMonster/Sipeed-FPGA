## Как загрузить готовую прошивку

Скачать [pr25_konsol_trial.fs](fs/pr25_konsol_trial.fs) в локальную папку. **Не переставлять PMOD** из проверенного положения под USB-A. Затем PowerShell 7:

```powershell
$fs = 'C:\GitHub\PR25-KonSol-DVI\pr25_konsol_trial.fs'
$expected = '1a0ad8cdf8be6ed7ffffdbfe943d547f94fada6a63a7549ccb8825e2c50e9053'
if ((Get-FileHash -LiteralPath $fs -Algorithm SHA256).Hash.ToLowerInvariant() -ne $expected) {
    throw 'FS SHA256 mismatch'
}
$cli = 'C:\Gowin\Gowin_V1.9.9Beta-4_Education\Programmer\bin\programmer_cli.exe'
& $cli --device GW5A-25A --cable-index 1 --run 2 --fsFile $fs
if ($LASTEXITCODE -ne 0) { throw "SRAM PROGRAM FAIL: $LASTEXITCODE" }
```

Путь `$fs` должен указывать на фактически скачанный файл. `--run 2` — запись **в энергозависимую SRAM**, не во Flash.

## Как устроено и как пересобрать

Собственная часть — `lab_top_konsol.sv`, она генерирует символы, псевдографические элементы и цвета по координатам пикселя. Видеотракт остаётся ранее аппаратно проверенным: исходная обвязка/генератор синхронизации, PLL и **закрытый IP Gowin DVI_TX_Top**. Мы заменили только RGB-генератор; TMDS-выводы и .cst не менялись. См. [описание интерфейса и лицензионных ограничений GOWIN DVI_TX](../../../ip/hdmi/gowin-dvi-tx/README.md).

**Ограничение воспроизводимости:** опубликованный `Build_KonSol_Trial.ps1` — оригинальный сценарий локального испытания. Он **не автономен**: использует рабочую папку исходного DVI-проекта и сверяет SHA256 эталонного `.fs`; без этих зависимостей он не запустится. Для независимой сборки необходимо получить соответствующий защищённый IP в Gowin EDA и восстановить видеотракт с совместимыми PLL/CST/SDC. В исходном опыте учебная обвязка была из [yuri-panchul/basics-graphics-music, commit 817bd4d](https://github.com/yuri-panchul/basics-graphics-music/tree/817bd4dac8ab45d5c22bdd78b441bedb80672cd0); учебный пример не хранится здесь как отдельный проект. Авторство upstream и правообладателя IP сохраняется.

**Лицензия:** собственный RTL и скрипт отделены от проприетарного IP; публикация `.fs` с включённым IP требует соблюдения применимой Gowin EULA. Не считать зашифрованный `DVI_TX` открытым кодом.

## Что доказано и что не доказано

**Доказано на плате:** появляется читаемый цветной экран KonSol, рамки, псевдографика и тест цветов. **Не доказано:** реальная файловая система, интерактивный терминал, аудио, продолжительная стабильность и полный STA sign-off. Для этой демонстрации SDRAM и внешняя клавиатура не требуются.
