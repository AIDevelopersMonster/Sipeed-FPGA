# PR25 USB HID → DVI 05 — клавиатура заработала на Tang Primer 25K

**Статус: USB HID KEYBOARD BOARD PASS (проверенные клавиши 1–4) / VIDEO BOARD PASS, 15.11.2026.** Аппаратный опыт подтверждён пользователем: при нажатиях цифровых клавиш на DVI-экране последовательно наблюдались реальные USB HID usage-коды `1E`, `1F`, `20`, `21`.

**Видео:** [YouTube Shorts — USB-клавиатура на FPGA](https://youtube.com/shorts/AShk8CMhZco).

## Состав проверенного опыта

- Плата: Sipeed Tang Primer 25K + Dock (GW5A-25A)
- USB-A: D+ **L6**, D− **K6** — напрямую к FPGA
- Видеовывод: работающий **Gowin DVI_TX_Top**, PMOD DVI, 640×480
- USB Host: [m1nl/usb_hid_host](https://github.com/m1nl/usb_hid_host), версия с Low Speed и Full Speed, без отдельного CPU
- Режимы S1: PASSIVE (электрическое обнаружение) ↔ HOST (USB-перечисление / отчёты)
- Отображение: TYPE, VID/PID, KEY1/KEY2/MOD, счётчики HID/TX
- Без внешней SDRAM и без зависимости от USB-UART; запись только в SRAM

| Нажатая клавиша | Код USB HID | Проверка |
| --- | --- | --- |
| 1 | `0x1E` | BOARD PASS |
| 2 | `0x1F` | BOARD PASS |
| 3 | `0x20` | BOARD PASS |
| 4 | `0x21` | BOARD PASS |

Крайняя правая двухразрядная область в строке ключей — **MOD**, байт модификаторов, а не KEY3. Одновременные шесть клавиш и полноценный текстовый ввод в этом опыте не проверены. Реальный USB-хаб не испытывался.

### Запуск

Оба файла должны лежать в одной директории. В PowerShell 7 с установленными Gowin, Programmer CLI и Git:

```powershell
& .\Build_USB_HID_DVI_05.ps1 -ProgramSRAM
```

Сборка получает закреплённые исходники сторонних проектов, проверяет SHA1 их Git-блобов, создаёт отдельный временный проект. Программирование только в **SRAM**; Flash не трогается.

**Важная граница доказательства:** физически проверенный бинарный файл `.fs` находится на машине оператора, но не предоставлен нам в этом чате. Здесь публикуются **ровно исходники и сценарий той версии**, которая дала аппаратный PASS. Мы не утверждаем, что новый rebuild дал тот же SHA256, и не создаём псевдо-«рабочую» прошивку. Если будет передан точный `.fs`, его можно добавить с проверкой SHA256.
