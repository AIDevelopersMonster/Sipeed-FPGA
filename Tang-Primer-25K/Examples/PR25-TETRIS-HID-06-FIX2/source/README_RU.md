# PR25-TETRIS-HID-06 — Тетрис на Tang Primer 25K + USB-клавиатура + PMOD DVI

**Статус:** PREPARE PASS / STATIC CHECK PASS. **GOWIN BUILD / SIM / TETRIS BOARD ещё не подтверждены**.

Это самостоятельный локальный эксперимент после аппаратно подтверждённой версии **PR25_USB_HID_DVI_05**. Её USB-клавиатура уже передала HID usage-коды `1=0x1E`, `2=0x1F`, `3=0x20`, `4=0x21` на Tang Primer 25K. Демонстрация: https://youtube.com/shorts/AShk8CMhZco

Тетрис реализован логикой FPGA **без CPU, SDRAM, UART-терминала, внешнего USB-host-контроллера и кадрового буфера**. Те же видеоконтроллер Gowin **DVI_TX_Top**, 640x480, разъём PMOD DVI, стандартный USB-A (D+ L6 / D- K6), PLL 60 MHz и оригинальный `m1nl/usb_hid_host` (Low/Full Speed) используются без изменений. `tetris_engine.sv` — новый независимый модуль; флаги и USB-ядро HID05 сохранены.

## Что реализовано

- Классическое поле **10x20**, 7 фигур, их вращение и столкновения.
- Фиксация фигуры, удаление заполненных строк, счёт, случайная следующая фигура, конец игры, новая игра.
- Горизонтальный авторепит при удержании клавиши (130 мс), обычное падение (520 мс), быстрое (50 мс).
- Аппаратный цветной растровый вывод поля и подсказок, без ROM для экранных строк.
- Проверка **6 одновременно удерживаемых HID key usage**; USB-пакеты обрабатывает уже проверенное HID05-ядро.
- Сохранение двух режимов диагностики: **PASSIVE/USB HOST** кнопкой S1 и **GAME/HID DIAG** клавишей F1.
- В игре видны **SCORE** (4 hex), **LINES** (2 hex), **NEXT**, **KEY** (последний код в HEX), **MOD** (байт модификаторов).
- В HID DIAG сохранены диагностические панели VID/PID, KEY1, KEY2, MOD и счётчики RX/TX прежней HID05.

## Управление

| Действие | Стрелки / основные клавиши | Резерв, подтверждённые на HID05 |
| --- | --- | --- |
| Влево | Left / A | **1** (`0x1E`) |
| Повернуть | Up / W | **2** (`0x1F`) |
| Вправо | Right / D | **3** (`0x20`) |
| Сбросить вниз | Space | **4** (`0x21`) |
| Ускоренное падение | Down / S | 5 (`0x22`, пока не проверена на плате) |
| Пауза / продолжить | P | — |
| Перезапуск игры | R | — |
| Игра ↔ диагностика HID | **F1** | — |
| PASSIVE ↔ USB HOST | **S1 на FPGA** | — |

При загрузке сначала PASSIVE с рабочей электрической диагностикой D+/D−. Один раз нажмите **S1** — переход в HOST, где по умолчанию включён **Тетрис**. При возврате в PASSIVE игровое поле и счёт сохраняются, тактирование игры приостанавливается. F1 переключает игру с прежней HID-диагностикой, не перезапуская USB Host.

**Примечание:** отсутствие реакции на стрелки само по себе не является ошибкой USB. Сначала проверьте ввод **1-2-3-4**, который уже работал в HID05. Сверяйте отображение KEY, если игра не реагирует.

## Повторение на Windows PowerShell 7

1. Скачайте `PR25_TETRIS_HID_06.zip` в папку `Downloads`.
2. **Не изменяйте** подключение PMOD DVI. Клавиатура в штатный USB-A платы.
3. В PowerShell:

```powershell
$zip = Join-Path $HOME 'Downloads\PR25_TETRIS_HID_06.zip'
if (!(Test-Path -LiteralPath $zip)) { throw "ZIP не найден: $zip" }
$dir = Join-Path $env:TEMP 'PR25_TETRIS_HID_06_Package'
Expand-Archive -LiteralPath $zip -DestinationPath $dir -Force

# Необязательная локальная симуляция ядра (MSYS2 Icarus iverilog/vvp):
& "$dir\tests\Run_Engine_Sim.ps1"

# Сборка Gowin и запись ТОЛЬКО в SRAM:
& "$dir\Build_Tetris_HID06.ps1" -ProgramSRAM
```

Симуляция при отсутствии Icarus необязательна: ошибка «Icarus not found» не означает ошибку прошивки, можно выполнить сценарий Gowin отдельно. `gw_sh.exe` и Programmer CLI используются из `C:\Gowin\Gowin_V1.9.9Beta-4_Education`. Включён контроль фиксированных Git blob SHA, отсутствие старой `.fs`, отдельный временный каталог `%TEMP%\PR25_TETRIS_HID_06`. **Запись Flash не выполняется; `--run 2` означает SRAM**. Ни один ранее работающий локальный проект и ветка GitHub скриптом не меняются.

### Первый аппаратный тест

После BUILD/PGRAM SRAM успеха:

1. На стартовом PASSIVE проверьте сигнал при подключении USB, как в HID-04/05.
2. Нажмите S1. Должна появиться игровая панель с полем 10x20 и начальной фигурой.
3. Клавиши **1** и **3** сдвигают фигуру, **2** поворачивает, **4** моментально опускает.
4. Клавиша **R** начинает новую игру; **P** ставит на паузу; **F1** открывает прежний диагностический экран.
5. Для успешного BOARD PASS требуется реальное наблюдение движения и фиксации хотя бы одной фигуры, не только вывод статического поля.

При ошибке сборки: выводите последние 80 строк лога `%TEMP%\PR25_TETRIS_HID_06\build_tetris_hid06.log`. Не утверждайте BUILD PASS по коду выхода `programmer_cli` без видео/фото игры.
