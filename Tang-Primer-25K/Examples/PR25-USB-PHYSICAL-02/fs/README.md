# fs — рабочая SRAM-прошивка

Точный бинарный файл `pr25_usb_attach_lite02.fs`, который был загружен на плату во время успешного испытания, **пока находится на ПК оператора** и ещё не добавлен в эту папку.

Сценарий [Publish_Verified_FS.ps1](../Publish_Verified_FS.ps1) позволяет сохранить **именно эту проверенную копию** и её SHA256 через GitHub CLI, не создавая Releases и не перезаписывая существующие файлы.

**Не выдавать повторно собранную прошивку за аппаратно проверенную без отдельного BOARD PASS.**
