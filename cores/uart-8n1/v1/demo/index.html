Временная диаграмма TXD

Номинально каждый бит занимает 234 такта системного генератора по 27 МГц. Визуализация здесь переключается по одному битовому интервалу, а не по каждому из 234 тактов.

02. Устройство кадра

10 бит на один байт

Покой: 1 (HIGH) START : 0 (LOW) DATA : D0 → D1 → ... → D7 PARITY: нет STOP : 1 (HIGH) → 1 + 8 + 1 = 10 бит

Для 115200 бод идеальное время бита ≈ 8,681 мкс. С делителем 234 при 27 МГц получается 8,667 мкс/бит, т.е. около 115385 бод. Идеальный UART-кадр занимает около 86,7 мкс на проводе.

03. Как работает RX

Приёмник не знает фазу передатчика

Наш uart_rx_8n1.v использует двухкаскадную синхронизацию входного сигнала с тактом FPGA, затем проверяет стартовый бит в его середине и выбирает D0…D7 по центрам следующих битовых интервалов.

IDLE → START → DATA → STOP → IDLE ↓ ↓ ↓ validate 8 bits validate STOP

Это не большинство голосов по 16 пробам и не auto-baud. Ошибочный стоп-бит создаёт framing_error, но не valid.

Где используется FIFO

USB-UART (PC) ↓ RX pin 18 uart_rx_8n1.v ↓ valid + data[7:0] sync_fifo.v ← приёмная очередь ↓ pop_valid + pop_data host00_hello.v ↓ tx_valid + tx_data sync_fifo.v ← очередь передачи ↓ uart_tx_8n1.v ↓ TX pin 17 USB-UART (PC)

Проверенные границы

UART TX/RX были выделены без изменения RTL из проверенной лаборатории LAB-02. В HOST-00.1 составная схема дала три физических ответа HELLO\n через COM10, при 0 внутренних нарушений Setup/Hold. Эта демонстрация описывает сигнальный протокол, но не является измерением формы реального сигнала на осциллографе.
