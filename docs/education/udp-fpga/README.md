## Где UDP в сетевой системе

Читайте [техническое дополнение: IPv4, UDP, TCP, Ethernet MAC, RMII, физический PHY RTL8201F](NETWORK_STACK_PHY_RU.md). Схематически:

~~~text
Приложение / PicoRV32
  → UDP (или TCP, альтернативный транспорт)
  → IPv4 + ARP в локальной сети
  → Ethernet MAC (кадры, FCS CRC32)
  → RMII (2-bit, 50 MHz для 100M)
  → RTL8201F PHY (кодирование и аналоговые сигналы)
  → трансформаторы / RJ45 / кабель
  → коммутатор → компьютер → приложение
~~~

UDP относится к стеку **TCP/IP**, но **не требует TCP**. Физический уровень обычно реализуется внешним PHY, а не логикой UDP.
