## Запуск

Дважды щёлкните `index.html`. Файл полностью автономный и работает в современном браузере **без локального сервера, библиотек и интернета**. Подходят Windows 10/11, Linux и macOS.

Нажимайте «Шаг» для последовательного просмотра 19 смысловых микроопераций. «До свечения» сразу показывает, как `SW` меняет MMIO-регистр и физический сигнал. «Авто» демонстрирует всю последовательность. Кнопки L1–L6 изменяют целевой светодиод и константу программы.

## Техническое содержание

- Цель: один светодиод на Tang Nano 9K (GW1NR-9C, 27 МГц).
- В программе используется четыре 32-битных инструкции: `LUI`, `ADDI`, `SW`, `JAL`.
- Результат `addi t1, zero, 1` — `x6=1`; `lui t0,0x20000` — `x5=0x20000000`.
- `sw t1,0(t0)` инициирует `mem_valid=1`, `mem_instr=0`, `mem_addr=0x20000000`, `mem_wdata=1`, `mem_wstrb=1111`.
- SoC записывает биты в `leds[5:0]`, а `assign led_n=~leds` активирует светодиод низким уровнем. В исходной привязке `led_n[0]` соответствует выводу 10 FPGA.
- `jal zero,stop` зацикливает процессор, LED остаётся включённым без дальнейших записей.

**Граница:** это *смысловая учебная симуляция*, а не потактовое исполнение оригинального Verilog. Транзакции `mem_valid/mem_ready` иллюстрируются отдельными фазами, но их тайминги, глубина FSM и логические задержки Gowin не моделируются. HTML не загружает FPGA, не заменяет Icarus Verilog и не доказывает аппаратную работоспособность этого отдельного четырёхинструкционного примера.

## Исходная учебная программа

См. `examples/led1_only.S`. Для получения аппаратного `.fs` её необходимо собрать вместе с нашим SoC, провести RTL-симуляцию соответствующим тестом и выполнить Gowin PnR. Сам HTML не компилирует Verilog.
