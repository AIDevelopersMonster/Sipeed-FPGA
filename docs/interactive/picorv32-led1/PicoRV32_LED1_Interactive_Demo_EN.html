1. Boot ROM (same mechanism as in rtl/boot_rom.v)

Synthesis implements the ROM contents in FPGA resources. The signal word_addr — is a word index: the lowest two byte-address bits are omitted.


  
2. Decoder excerpts from vendor/picorv32/picorv32.v
decoded_rs1 <= mem_rdata_latched[19:15];
decoded_rs2 <= mem_rdata_latched[24:20];

// First, the STORE family is recognized by opcode.
is_sb_sh_sw <= (mem_rdata_latched[6:0] == 7'b0100011);

// SW is then selected by funct3.
instr_sw <= is_sb_sh_sw && (mem_rdata_q[14:12] == 3'b010);

  
These lines are excerpts from different decoder sections, combined for teaching. They are not a standalone Verilog module.

  
3. Actual address decoding in rtl/picorv32_soc.v
wire is_mmio = (mem_addr[31:8] == 24'h200000);

// Inside the clocked always block:
if (mem_valid && !mem_ready) begin
    if (is_mmio) begin
        case (mem_addr[7:0])
            8'h00: begin
                if (|mem_wstrb && mem_wstrb[0])
                    leds <= mem_wdata[5:0];
                mmio_rdata <= {26'b0, leds};
                mem_ready <= 1'b1;
            end
        endcase
    end
end

assign led_n = ~leds;

  
4. Board pin constraints constraints/tang_nano_9k.cst
