ПОШАГОВО

1. Загрузите PiKoSoL

На отдельной странице PiKoSoL WebUSB Loader выберите tangnano9k, загрузите проверенный .fs только в SRAM. Затем закройте вкладку программатора, если она удерживает USB.

СВЯЗЬ

2. Подключите UART

В Chrome/Edge нажмите «Подключить COM», выберите последовательный порт FT2232 Interface B, затем «Проверить PicoRV32». JTAG-интерфейс A и UART-интерфейс B — разные каналы.

ПРОТОКОЛ

3. Отправляйте команды

Строковые команды завершаются CR, вывод читается с реального UART. В GFX+KEYS работает поток одиночных клавиш без Enter. HTML не эмулирует RISC-V.
