ШАГ 02 · USB-JTAG

Подключите Tang Nano 9K

Выберите в окне Chrome устройство JTAG Debugger (FT2232, VID:PID 0403:6010). В Windows интерфейс A должен работать через WinUSB; UART-интерфейс B не меняем.

Разрешение браузера на WebUSB ещё не предоставлено.
ШАГ 03 · SRAM

Программирование

Фиксированная команда:

openFPGALoader -c ft2232 -b tangnano9k pikosol.fs

Кнопка доступна после выбора файла и USB-JTAG. Во время загрузки не отключайте USB. Успешное завершение программы отдельно проверяйте на HDMI.

01 / Подготовка

Прошивка загружается в SRAM FPGA. JTAG A: WinUSB. UART B: обычный COM-порт.

02 / WebUSB

Chrome или Edge по HTTPS запрашивает разрешение на конкретную USB-плату. Доступ не предоставляется автоматически.

03 / Терминал

После загрузки FPGA переходите в PiKoSoL Control Center и подключайте UART через Web Serial.
