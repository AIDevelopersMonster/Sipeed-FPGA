03 · FAT32 / WEB SERIAL

Живой терминал PiKoSoL

После успешной загрузки SD-08 нажмите «Подключить COM» и выберите FT2232 Interface B. Команды FS, DIR, TYPE PIKO.TXT выполняются самим PicoRV32. Программная запись на SD запрещена аппаратно.

04 · EMBEDDED FLASH / FUTURE GATE

Постоянная загрузка без SRAM

GW1NR-9C поддерживает внутреннюю энергонезависимую Flash. Но запись стирает существующую конфигурацию. Пока не подтверждены оригинальный заводской образ и проверенная процедура восстановления, кнопки Flash здесь нет. Профили Sipeed — официальные примеры, не доказанная заводская прошивка.

Flash не программируется. Не путайте содержимое FPGA configuration Flash с содержимым SD-карты и программой во внешней SPI Flash.
