Подключение к настоящей плате через Web Serial

В Chrome/Edge по HTTPS выберите FTDI UART COM своего Tang Nano 20K (на испытательном ПК — COM25), 115200 8N1. Перед подключением закройте PuTTY и PowerShell-загрузчик. Браузер не подключается без нажатия кнопки. Разрешены только help, mem_list и известные статусные регистры UART. Команды записи/boot/IRQ заблокированы кодом интерфейса.

Отключено. Веб-страница не меняет содержимое Flash и SDRAM.
