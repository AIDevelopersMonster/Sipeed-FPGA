Как читать инструкцию
32 бита записываются в little-endian порядке; например, байты 17 21 00 10 означают машинное слово 0x10002117. Форматы R, I, S, B, U, J задают расположение регистров, immediate и opcode. Псевдокоманды nop, ret, mv — соглашения ассемблера над базовыми инструкциями.
Конкретный пример можно выбрать в справочнике, затем нажать «К примеру в исследователе». Чтобы увидеть правильные операнды во время запуска BIOS, запускайте модель с PC=0, а не с произвольного адреса.

LAB-20.5 · LITEX UART / CSR
Два мира CSR: регистры CPU и периферия через Wishbone
Одинаковая аббревиатура обозначает два разных адресных пространства и два разных механизма доступа. Ниже приведены настоящие машинные инструкции заводского ROM.

 
Семь аппаратных чтений CSR · 07.11.2026
BOARD READBACK

RISC-V architectural CSR
ИНСТРУКЦИЯ CSR

    
12-битный номер регистра 0x305, 0x300, 0x304, 0xBC0, 0xFC0 кодируется прямо в слове инструкции 0x73. Это не адрес в 4-гигабайтном пространстве памяти.

    
csrrw zero, mtvec, a0
PC=0x000000C0 · CSR=0x305 · значение 0x00000020. Новый адрес обработчика исключений.
csrrsi zero, mstatus, 8
PC=0x000017C4 · установить бит MIE=3 глобального разрешения машинных прерываний.

    
Стандартные: mtvec, mie, mstatus. Специфические VexRiscv/LiteX: 0xBC0 — маска отдельных внешних IRQ, 0xFC0 — ожидающие внешние IRQ.

  

  
LiteX peripheral CSR = MMIO
LOAD / STORE

    
Периферийный CSR находится по физическому адресу 0xF0003010. CPU обращается к нему обычными lw и sw через dBus Wishbone и мост Wishbone2CSR.

    
lui a5, 0xF0003 → a5=0xF0003000
lw a4, 16(a5) → UART_EV_PENDING
sw a4, 16(a5) → подтвердить ожидающие события (W1C)
sw a4, 20(a5) → UART_EV_ENABLE=3

    
Важно: здесь нет инструкции csrrw. Номер 0xF0003010 не поместился бы в 12-битное поле архитектурного CSR.

Лаборатория: как работает uart_init()
ВИРТУАЛЬНЫЙ ПРИМЕР, НЕ ПЛАТА

 
Выбери состояние двух ожидающих событий. Имитация выполняет именно последовательность из заводского ROM: pending_read → pending_write → enable=3 → IRQ_MASK|=1. Здесь нет аппаратного чтения COM25 или моделирования тактов.

 

 

 

 

  
Пять слоёв разрешения IRQ
UART FIFO event → ev_pending & ev_enable → IRQ line 0 → CSR_IRQ_MASK 0xBC0 bit 0 → mie.MEIE bit 11 + mstatus.MIE bit 3 → mtvec 0x20
Это логические условия разрешения прерывания; флаги и сигнал IRQ должны реально появиться. Запись mie=0x880 не создаёт прерывание сама по себе.

  
Безопасный эксперимент в LiteX BIOS
Только чтение статусных регистров (не всего блока подряд):
mem_read 0xF0003004
mem_read 0xF0003008
mem_read 0xF0003010
mem_read 0xF0003014
Значение ev_pending может меняться, пока терминал передаёт символы. Не писать в эти адреса для диагностики. Не используем mem_read 0xF0003000 24: такое чтение включает uart_rxtx.

uart_init() / uart.c ↗UART registers ↗EventManager / W1C ↗Wishbone2CSR bridge ↗

CLAIM DISCIPLINE
Что подтверждено, а что пока неизвестно
PiKoSoL разделяет измеренное на физической плате, математически реконструированное и смоделированное.

 
Подтверждено данными
  • Каноническая ROM: 32 768 байт, SHA-256 3347be74…5bc. Архивный дамп: 131 072 байта, SHA-256 fac8e6e6…edb65.
  • Четыре абсолютно одинаковых участка по 32 КиБ.
  • Непрерывная зона инструкций по 0x4BC4 включительно, затем область данных и нулевое заполнение.
  • Прямая команда JAL, SP, mtvec, копирование .data и обнуление .bss.
  • ROM содержит строковые константы и таблицы BIOS.
Границы имитации
  • Это интерпретатор семантики инструкций, а не RTL-модель VexRiscv.
  • Нет циклоточной модели конвейера, кэша, SDRAM или Wishbone.
  • MMIO 0xF0003010 не моделируется; на первом чтении программа останавливается.
  • IRQ mask CSR 0xBC0 реализован как программный регистр по исходникам VexRiscv, но сами источники прерываний не моделируются.
  • Возможность исполнения M/C нельзя отвергать только потому, что эти инструкции отсутствуют в BIOS.

Как использовать справочник
  1. В разделе «Исследователь» выберите адрес 0xB0 и изучите поля AUIPC.
  2. Сбросьте модель на 0x00000000 и нажимайте «Шаг», наблюдая установку SP и mtvec.
  3. Кнопкой «До первого MMIO» пройдите инициализацию SRAM и остановитесь на реальной границе модели.
  4. В «Справочнике ISA» выберите команду и откройте её реальные экземпляры из ROM.
  5. В «Карте ROM» изучите четыре повторения и сравните с реестром SHA-256.
Проект работает без подключения к интернету. Файлы BIN импортируются только в память браузера и никуда не отправляются.
