# LAB-03.4 v0.3 — два маршрута: RTL ↔ FPGA, команды 0 и 4

**Платформа:** Sipeed Tang Nano 9K / GW1NR-9C, PicoRV32 RV32I, Windows 10 / PowerShell 7, Python 3, Icarus Verilog.
**Состояние на момент подготовки:** команда **4** ранее получила аппаратный и RTL BUS CORE PASS в v0.2; **0** имеет шесть аппаратных захватов, но независимое RTL-сопоставление команды 0 ещё должно быть исполнено на Windows. Офлайн-тесты нового анализатора — не RTL-эксперимент.

## Цель

Расширить существующий испытательный маршрут LAB-03.2, сохранив работающую последовательность `READY → 4 → T → T → C → 1 → T`, добавив в конце `C → 0 → T`. В одной фактической RTL-симуляции проверить обе команды и сопоставить их с шестью аппаратными дампами каждой из серии LAB-03.3.

**Ничего не перезаписывается в исходниках:** `tools/lab03_4_extend_tb.py` читает локальный `tests/tb_lab03_2_uart.v`, проверяет уникальные якоря и создаёт расширенную копию в `build/lab03_4/rtl_compare_v03/run_.../tb_lab03_2_uart_v03.generated.v`. Исходный testbench, прошивки, RTL, драйверы, COM10, SRAM и Flash не затрагиваются. Если якоря неожиданно изменились, расширение останавливается с `LAB03_4_V03_TB_BLOCKED`, а не правит файл приблизительным поиском.

## Установка на Windows — только новые файлы

Рабочий корень `C:\GitHub\Sipeed-FPGA`. После загрузки архива в Downloads:

```powershell
Set-Location C:\GitHub\Sipeed-FPGA
Expand-Archive "$HOME\Downloads\LAB03_4_RTL_Bus_Equivalence_v0.3.zip" -DestinationPath . -Force
```

Архив содержит только **новые имена файлов**, а не замену прежнего v0.2 или ваших незакоммиченных LAB-03.2.

Сначала проверка Python-анализа (архив аппаратных данных должен быть в Downloads):

```powershell
python .\01-PicoRV32\tests\test_lab03_4_v03.py
```

Ожидаются `Ran 13 tests` и `OK`. Негативные тесты специально проверяют отказ анализатора принимать ошибочные данные. В самих unit-тестах аппаратный дамп используется **как имитация RTL**. Эти тесты не удостоверяют фактическую Icarus-симуляцию.

## Запуск настоящего RTL-теста и сравнения

```powershell
& .\01-PicoRV32\tools\run_lab03_4_rtl_v03.ps1 `
    -Evidence "$HOME\Downloads\LAB03_3_EVIDENCE.zip"
```

Запуск: проверит SHA256 ROM и имеющегося `.fs`; зафиксирует хеши исходников, текущее состояние Git, создаст копию TB, сохранит прежние фиксированно названные **генерируемые** дампы в уникальную папку `previous_generated`, скомпилирует RTL, запустит Icarus, проверит оба PASS-маркера и исходный T3-декодер (команды 4, 4 повторно, 1, 0), дополнительно проверит побайтовую идентичность повторного чтения T. После этого выполнит сверку 0 и 4 со всеми двенадцатью аппаратными снимками.

Если есть несоответствие или отсутствует новый дамп, будет код ошибки; **PASS запрещён**.

При полном совпадении **ожидаем**, но пока НЕ утверждаем, следующий вывод:

## Условия PASS

1. Запущен Icarus на том же ROM с ожидаемым SHA256, исходный код не изменён в ходе симуляции.
2. Успешны старые сценарии (`4`, повторный `T`, `C`, `1`, `T`) и новый (`C`, `0`, `T`).
3. Сырые RTL-T3 обоих маршрутов валидны по оригинальному декодеру, ROM и ожидаемой LED-записи.
4. Все 12 аппаратных дампов проверены по сохранённым SHA256; все аппаратные FETCH соответствуют ROM.
5. Внутри каждой команды нормализованный участок начиная с единственного FETCH PC `0x048` и заканчивая LED_WRITE полностью совпадает по `(kind, address, value)` для RTL и аппаратной серии.
6. Измеренные относительные циклы и участки UART polling **не** приравниваются к моментам завершения инструкций (retirement); не декларируется потактовая эквивалентность.

### Ограничения и особые случаи

- Наблюдения `0` и `4` относятся к двум командам и одному зафиксированному ROM; не охватывают все входы или ISA.
- UART polling создаёт различное количество FETCH до PC `0x048`; исключается только этот префикс, предварительно проверяемый как повторяющаяся последовательность `0x038,0x03C,0x040,0x044`.
- Гарантия совпадения **исходников** RTL и запрограммированного .fs не заменяется совпадением SHA256 описанного .fs; полной аттестации RTL ↔ bitstream для произвольных трасс нет.
- Текущий Git HEAD не обозначает полностью локальную сборку, поскольку на момент испытаний были незакоммиченные исходники. Публикацию Git следует делать отдельно после аудита содержимого.
- Компиляция и симуляция в этой подготовительной среде не выполнялись: локальный полный RTL LAB-03.2 не был доступен. PASS v0.3 может присвоить только фактический запуск на вашем компьютере.
