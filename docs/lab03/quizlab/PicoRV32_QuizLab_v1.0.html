Журнал результатов

Методическая модель QuizLaw → PicoRV32 QuizLab

Сохранена структура юридического тренажёра: тренировка, экзамен без подсказок до проверки, повтор ошибок, фильтры, четыре типа заданий, история, протокол Markdown и перенос прогресса JSON.

Три области знаний: LAB-03 (реальные 12 захватов), RV32I (машинная кодировка и ROM), SoC (подключение PicoRV32 к UART, MMIO и трассировщику). Вопросы имеют категории доказательной опоры: BOARD, ROM, ISA, RTL, PROTOCOL.

Принцип достоверности: FETCH ≠ retirement. Аппаратный наблюдатель фиксирует принятую выборку инструкций и отдельную запись в LED MMIO, но не весь поток завершённых инструкций, не работу DRAM и не оптическое состояние LED. Прохождение квиза не является сертификацией FPGA.

Материалы проекта: GitHub · LAB-03. Все ссылки-основания есть в каждом задании, само приложение офлайн.
