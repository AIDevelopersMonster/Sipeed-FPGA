# PicoRV32 QuizLab v1.0 · HTML-квиз по реальной LAB-03

**Педагогическая механика QuizLaw · самостоятельная реализация · полностью офлайн**

50 проверяемых вопросов с источниками, привязанными к программе и оборудованию **Sipeed Tang Nano 9K / PicoRV32 (RV32I)**. Это не общий случайный тест по RISC-V: задания по SoC относятся к конкретному `picorv32_soc_lab03.v`, а вопросы по аппаратным измерениям — к реально сохранённым T3-захватам.

## Запуск

Откройте [PicoRV32_QuizLab_v1.0.html](PicoRV32_QuizLab_v1.0.html) двойным щелчком в **Edge / Chrome**. HTML содержит CSS, JS и весь банк вопросов, поэтому сервер, сеть и Python для использования не нужны.

Режимы и возможности:

- **Тренировка** — проверка после ответа, пояснение и ссылка на подтверждающий исходник;
- **Экзамен** — настройка числа заданий и фильтров; ключи появляются после завершения;
- **Повтор ошибок** — выборка вопросов, на которые ранее ответили неправильно;
- четыре вида: **один ответ**, **несколько ответов**, **сопоставление**, **порядок**;
- фильтры: раздел, уровень сложности, вид задания и доказательная основа;
- локальная история, экспорт отчёта `.md` и прогресса `.json`;
- отдельный побитовый **декодер S/B/J/I/U** на примерах реальной ROM.

Банк: **12** вопросов по аппаратной LAB-03, **20** — по RV32I и ROM, **18** — по SoC/RTL. По типам: 35 одиночных, 6 множественных, 5 сопоставлений, 4 последовательности.

**Важное ограничение:** `FETCH` — принятое шинное чтение слова инструкции, **не** instruction retirement. Доступные архивные трассы не измеряют архитектурное завершение инструкций, уровень сигнала на контактах и яркость LED. Результат экзамена отражает правильность решений **этого банка вопросов**, а не сертификацию процессора или FPGA.

Банк поддерживается в [questions.json](questions.json), рядом есть [JS-представление](questions.js), [шаблон страницы](index.template.html) и генераторы:

```powershell
cd C:\GitHub\Sipeed-FPGA\docs\lab03\quizlab
python .\verify_quiz.py
python .\build_standalone.py --check
# Если в исходных заданиях появились запланированные изменения:
python .\build.py
python .\build_standalone.py
```

`build.py` воспроизводит исходный банк вопросов из Python-кода; для редактирования уже существующего банка достаточно изменить `questions.json` и выполнить `build_standalone.py`. Команда с `--check` сравнивает встроенный банк с исходниками, не изменяя файлы.

`test_browser.py` — необязательный тест Playwright/Chromium; простому запуску квиза он не нужен. Автоматически проверить взаимодействия Chromium в контейнерной среде не удалось из-за запрета локальной навигации. Рекомендуется проверить тренировку и экзамен в браузере целевого ПК.

Для резервного копирования результатов используйте экспорт JSON. История хранится в `localStorage` данного браузера и может быть недоступна после смены браузера или очистки данных.
