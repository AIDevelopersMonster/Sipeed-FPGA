# Системы на FPGA

Здесь собираются целые SoC из общих компонентов. Системная архитектура не равна ни одному конкретному FPGA bitstream.

- [PiKoSoL](pikosol/README.md) — PicoRV32 + MMIO + UART + HDMI; будущая SD/FAT32 интеграция.

Сейчас это **навигационный уровень**, а не перенос всех проверенных реализаций из прежних каталогов.
