# Tang Primer 20K + Dock — начало работы

**Состояние на 12.11.2026:** каталог создан, реальные сборки и испытания на этой плате здесь ещё не зафиксированы.

## Назначение

Самостоятельная лаборатория **Sipeed Tang Primer 20K / GOWIN GW2A-LV18**. Главное направление — собственные процессоры и SoC на FPGA. Не путать с отдельной лабораторией **Tang Primer 25K / GW5A-LV25**.

## Комплектация и ограничения

- Пользователь подтвердил наличие **обеих** плат: Tang Primer 20K и Tang Primer 25K.
- Рекламные материалы Primer 20K + Dock перечисляют DDR3 1 Gbit, Flash 32 Mbit, HDMI, Ethernet 10/100, USB, SD, камеру, дисплейные разъёмы и PMOD. **Наличие, разводку, ревизию и работоспособность каждого интерфейса нужно проверять по конкретному Dock и его схеме.**
- Точный suffix FPGA, распиновка, осцилляторы, версия Gowin EDA и способ загрузки пока не задокументированы лабораторными измерениями.

## Очерёдность

1. **PR20-00 — привести плату в рабочее состояние:** фотография маркировки, схема, физические подключения, обнаружение программатора, тест LED/UART, тактирование и отчёт STA.
2. **PR20-01 — PicoRV32:** минимальный SoC с ROM/BRAM, UART, GPIO и загрузкой программы; повторяемый тест на реальной плате.
3. **PR20-02 — LiteX/VexRiscv:** отдельная система; сравнивать с PicoRV32 только при сопоставимых частотах, памяти и задачах.
4. **PR20-03 — PiKoSoL/KonSol:** текстовый терминал, графика, загрузка/скачивание файлов с Windows, управление файлами и выполнение программ BASIC/Forth там, где поддерживается программной средой.
5. Затем — контроллеры DDR3, HDMI, Ethernet, SD, USB, DMA и собственная архитектура CPU, по результатам реального bring-up.

## Правило подтверждения

- `PLAN` / `NOT TESTED` — идеи и задачи;
- `SIM PASS` — симуляция;
- `BUILD PASS` — синтез и размещение;
- `STA PASS` — выполненные временные ограничения;
- `BOARD PASS` — воспроизводимое выполнение на **Tang Primer 20K**, с указанными сборкой, инструментами и наблюдением.

**Прошивку Flash по умолчанию не трогаем.** Первый запуск — SRAM/JTAG при наличии подтверждённого безопасного способа.
