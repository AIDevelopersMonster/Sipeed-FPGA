# PR20-02 — LiteX / VexRiscv on Tang Primer 20K

**Status: PLAN / NOT TESTED.**

Experiment with a VexRiscv-based SoC and document the bus, memories, UART, timers and boot path. A LiteX BIOS known from **Tang Nano 20K** is not a factory BIOS for this model and cannot be assumed compatible.

Comparison with PR20-01 is valid only after documenting exact tool versions, core configurations, frequencies, memory topology and matching workloads.
