# PR20-01 — PicoRV32 on Tang Primer 20K

**Status: PLAN / NOT TESTED.**

Proposed minimal SoC: PicoRV32 CPU, ROM/BRAM, memory-mapped GPIO and UART, timer and a reproducible software test. Adapt reusable RTL and diagnostic ideas from PiKoSoL on Tang Nano 9K, but generate **new** Primer 20K pin constraints, clocks and device-specific IP.

Deliverables when implemented: RTL, software source, build steps, resource/STA report and board observation. Do not treat results from Nano 9K as Primer 20K BOARD PASS.
