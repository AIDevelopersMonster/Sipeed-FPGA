# PR20-04 — NESTang v0.4: NES + клавиатура ПК на Tang Primer 20K Dock

**Фактический результат 19.11.2026:** BOARD PASS — запуск NES-игры **Spacegulls 1.1**, изображение HDMI, управление первым игроком с клавиатуры/пульта ПК, прыжок и полёт проверены на плате. **Звук отсутствует / не подтверждён.**

**Оборудование:** Sipeed Tang Primer 20K + Dock (GW2A-18C). Это **не** Tang Nano 20K и **не** Tang Primer 25K.

Основа: [NESTang v0.4, nand2mario](https://github.com/nand2mario/nestang) (ядро NES первоначально основано на [fpganes](https://github.com/strigeus/fpganes)). Для нашей платы исправлено назначение линии DDR3 chip select: **`DDR3_nCS → P5`**. Управление реализовано через программу на ПК и UART COM10, **не через USB-клавиатуру, непосредственно подключённую к FPGA**.

## Содержимое и статус файлов

| Файл | Назначение |

| `TP20_NESTANG_CS_P5.fs` | Проверенная SRAM-конфигурация **без экспериментального PT8211**. Должна быть добавлена из проверенного локального файла |
| `NESTang04_Keyboard_COM10.ps1` | Локально проверенный скрипт загрузки ROM и управления с ПК. Должен быть добавлен из проверенного локального файла |
| `README.md` | Эта инструкция |

**Важно:** наличие README не означает, что оба локальных файла уже загружены в GitHub. Проверяйте их наличие в папке. **Нельзя использовать** вместо рабочей прошивки экспериментальную сборку `TP20_AUDIO_BUILD_*`, новые аудиокандидаты или исходную `nestang-0.4-dock.fs` без исправления P5.

Никаких автоматических GitHub Releases/тегов и никаких нерабочих прошивок.

## Загрузка FPGA в SRAM — без записи Flash

В PowerShell из папки с файлами:

```powershell
$cli = "C:\Gowin\Gowin_V1.9.9Beta-4_Education\Programmer\bin\programmer_cli.exe"
$fs = (Resolve-Path ".\TP20_NESTANG_CS_P5.fs").Path
& $cli --device GW2A-18C --run 2 --fsFile $fs --cable-index 1
```

Проверить успешное завершение SRAM Program и заставку NESTang на HDMI. **Flash не изменять.** При отключении питания SRAM-конфигурация теряется.

## Загрузка игры и управление клавиатурой компьютера

Подключить ПК к UART платы и убедиться, что он доступен как COM10. Закрыть MobaXterm, другой `loader.exe` и любые программы, удерживающие COM10. Клавиатура подключена к ПК.

Из папки, где находятся скрипт и отдельно полученный ROM:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass `
  -File ".\NESTang04_Keyboard_COM10.ps1" `
  -Rom ".\Spacegulls-1.1.nes" `
  -Port COM10
```

**Не включать ROM в этот репозиторий.** Путь к ROM заменить на свой; COM-порт тоже может отличаться. Скрипт должен продолжать работать во время игры.

**Подтверждённый сценарий управления:** стрелки — перемещение, кнопка NES A — прыжок; **быстрые повторные нажатия NES A** позволяют летать в Spacegulls. Enter/OK — Start. В варианте с проверенным RF-пультом левая кнопка мыши соответствует NES A, правая — NES B. Конкретную раскладку клавиш обычной клавиатуры ПК следует сверять с `NESTang04_Keyboard_COM10.ps1`, а не предполагать её по названию файла.

Сообщение в Spacegulls `PLAYER 2: PRESS A TO JOIN` — **не обязательное условие**. Для одиночной игры второй геймпад не требуется.

## Подтверждения и ограничения

- **BOARD PASS:** Spacegulls 1.1 загружена, управление, прыжок и полёт проверены на реальной плате.
- **Не проверено:** комплексная совместимость всех ROM и долговременный стресс-тест DDR3.
- **Звук:** в этой аппаратно проверенной сборке не получен. Эксперимент с выводом на PT8211 / J10 является **отдельной, ещё не прошедшей BOARD PASS разработкой**, не заменяет рабочий вариант.
- **Сохранение:** только в SRAM; без записи внешней Flash.
- Для публикации бинарника нужен его **точный локальный SHA256** и файл, который реально проверялся на плате.
