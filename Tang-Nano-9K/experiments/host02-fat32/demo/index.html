03. Инспектор настоящего файла
Опционально · работает полностью офлайн






Открыть indexer_volume_guid.bin


HOST-02 сохранил на компьютере файл размером 76 байт. На видео можно загрузить его сюда и показать точную структуру без повторного обращения к FPGA.



Файл пока не выбран. Подтверждённая по журналу структура: 76 байт UTF-16LE, строка GUID в фигурных скобках.



7B 00 ····· [данные скрыты] ····· 7D 00


По умолчанию идентификатор скрыт, чтобы не публиковать уникальное значение тома в видео или скриншоте. Снятие флажка снова скрывает его.






Почему ровно 76 байт?


GUID с фигурными скобками: 38 символов
UTF-16LE для ASCII-символов: 2 байта на символ

38 × 2 = 76 байт




7B 00 = «{»
Первый символ UTF-16LE.


7D 00 = «}»
Последний символ UTF-16LE.




В файловой записи указано 76 байт, хотя выделенный кластер содержит 32768 байт. Python берёт только первые 76 байт. Оставшаяся часть кластера не входит в содержимое файла.


Проверка локального файла станет доступна после его выбора. Без файла мы не выводим вымышленный GUID.

Почему архитектура удачна


Плата передаёт сектора через UART → FIFO → SDHC SPI без знания о FAT32. Python получает ровно 512 байт, разбирает MBR, VBR, FAT и записи каталогов, вычисляет кластер и извлекает нужную длину файла.


Можно совершенствовать парсер FAT32, не изменяя и не перепрошивая уже проверенную аппаратную часть. А замена UART на другой транспорт не должна менять правила FAT32.


HOST-02 завершена как учебный read-only эксперимент. Следующий этап должен иметь отдельные критерии и не менять работающий HOST-01.








Источник фактов: протоколы и результаты аппаратных испытаний HOST-01/HOST-02 от 24.10.2026; см. INFO/ROOT, подкаталог и файл. Фактические LBA файла вычислены из подтверждённой геометрии. Секторные счётчики из разных отдельных команд не суммируются в единое непрерывное измерение.


Учебная интерактивная модель, не аппаратный эмулятор: браузер не использует COM-порт, не обращается к SD-карте и не передаёт содержимое загруженного BIN. HTML, CSS и JavaScript работают автономно, без внешних библиотек или сетевых запросов.
