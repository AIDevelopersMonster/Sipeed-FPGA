# PiKoSoL — RISC-V компьютер

Рабочая версия: PicoRV32 RV32I, UART, HDMI TERM/GFX, светодиоды. Аппаратно проверенная Nano 9K сборка находится в `01-PicoRV32/lab04`, [отчёт LAB-04.4](../../docs/lab04/LAB044_ACCEPTANCE_2026-10-23_RU.md).

SD-контроллер уже испытан [в самостоятельной периферийной работе](../../examples/peripherals/sd-card/01-sector-read/README.md), но **ещё не интегрирован в PiKoSoL**. FAT32 и multi-LBA не объявлены аппаратно проверенными.

Будущая активная система будет ссылаться на единые IP: SPI, UART, SD, видео. Board target подбирает уникальные clock/PLL/CST/SDC и доступные функции. Старые LAB-04/05 не переносятся, чтобы сохранить приёмочные свидетельства.
