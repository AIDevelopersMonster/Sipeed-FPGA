# Самостоятельные лабораторные FPGA

- [SPI-01 — обмен одним байтом, Mode 0](spi/01-mode0-byte/README.md): базовый аппаратный SPI, самостоятельный testbench.
- [SD-01 — FPGA ↔ microSDHC](../../boards/tang-nano-9k/experiments/sd-sector0/README.md): самостоятельная аппаратная реализация для Tang Nano 9K, без RISC-V.

**Разные цели:** SPI-01 изучает тактирование и байтовый обмен; SD-01 использует SPI для команд SDHC. Архитектуры этих блоков можно сравнивать и заменять в следующих исследованиях, не переписывая исторические протоколы.

Сейчас образец SD-01 зафиксирован отдельно от развиваемого PiKoSoL. Неудачные ветки опытов, ограничения и альтернативы сохраняйте как документированные результаты, а не как неиспользуемые функции рабочей системы.
