# Самостоятельные FPGA-примеры

Учебные лабораторные сгруппированы по **изучаемой технологии**, а не по процессору. [Открыть каталог периферии](peripherals/README.md).

SPI, UART, SD и HDMI могут демонстрироваться без PicoRV32. Здесь находится независимая точка входа для каждого примера. RTL сейчас используется из исходных проверенных лабораторных без дублирования. Различия плат описаны в [boards](../boards/tang-nano-9k/README.md), общие модули — в [ip](../ip/README.md).

Сборочные скрипты создают только bitstream-кандидаты и **никогда автоматически не программируют FPGA**.
