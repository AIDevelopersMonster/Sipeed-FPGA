Как читать строку протокола T3?

Формат E:INDEX:CYCLE_KIND:ADDRESS:VALUE. Каждый параметр — 32 бита в hex. Старшие два бита поля CYCLE_KIND[17:16] задают вид события (1 = FETCH, 2 = LED_WRITE), младшие 16 бит — относительный счётчик циклов.

ПРАКТИКА / ЧИТАЕМ МАШИННОЕ СЛОВО

От кода инструкции до LED_WRITE

0x01D2A023 — это машинное слово sw t4, 0(t0) по адресу PC=0x100. Стенд расшифровывает его как Store Word. Регистр t0 содержит базу MMIO 0x20000000; t4 — маску светодиода, выбранную программой. Отдельное событие LED_WRITE удостоверяет принятую запись этой маски на шине.

Не следует выводить конкретные значения всех регистров из FETCH — трассировщик не снимает состояние регистрового файла. Привязка t0 и t4 основана также на анализе исходной программы и MMIO-записи.

САМОПРОВЕРКА

Контрольные вопросы

Почему FETCH нельзя назвать исполненной инструкцией?

FETCH фиксирует принятый шиной запрос слова из ROM. Архитектурное завершение (retirement) отдельно не наблюдается; запросы по неверному пути после переходов также могут появиться.

Почему число FETCH одной команды меняется?

До обработки принятого UART-символа процессор повторяет цикл опроса при неопределённом моменте прихода байта. Сравнение нормализованного участка устраняет этот переменный префикс, не объявляя его ошибкой.

Что доказывает совпадение последовательностей?

Для выбранных команд и наблюдаемых шинных сигнатур совпадает порядок событий в исследуемом участке. Оно не доказывает потактовую или полную функциональную эквивалентность процессора.

05 / QUICK REFERENCE

Термины, адреса и команды

Краткий справочник по стандартной терминологии цифрового проектирования. Основные термины дублируются подсказками в нужных местах интерфейса.

Процессор и шина

FPGA Field-Programmable Gate Array
Программируемая логическая интегральная схема; в этом опыте реализует PicoRV32 и регистратор.
RTL Register Transfer Level
Описание цифровой логики на уровне регистров и передач; эталон изучаемой аппаратной реализации.
RV32I RISC-V Base Integer ISA
Базовый 32-битный набор целочисленных инструкций, который использует прошивка.
PC Program Counter
Адрес инструкции. В T3 поле ADDRESS для FETCH показывает адрес запрошенного машинного слова.
Instruction fetch
Принятая процессорной шиной выборка слова инструкции из ROM. Не эквивалентна instruction retirement.
Instruction retirement
Архитектурное завершение инструкции. Наш регистратор не наблюдает его напрямую.
MMIO Memory-Mapped Input/Output
Доступ к периферии посредством обычных адресов памяти; запись LED выполняется по 0x20000000.
Polling
Повторный опрос регистра состояния UART в ожидании поступления байта.

Протокол и измерение

UART Universal Asynchronous Receiver/Transmitter
Асинхронный последовательный интерфейс. В лаборатории используется 115200 8N1.
8N1
8 бит данных, без бита чётности, 1 стоп-бит; скорость 115200 бод.
Trace / захват
Записанная последовательность принятых шинных событий с относительными метками циклов.
Snapshot
Снимок регистратора; повторная команда T читает его, не очищая.
Core trace
Нормализованный сравнимый участок от FETCH PC=0x048 до LED_WRITE включительно.
SHA-256
Криптографическая контрольная сумма для проверки тождественности файлов. Не заменяет чтение SRAM FPGA.
Disassembly
Преобразование машинного слова в мнемонику и операнды инструкции.
Active-low
Светодиод на плате включается низким электрическим уровнем на выводе. Логическая маска на стенде показана до инверсии выводов.

Происхождение данных и ограничения

Архив LAB-03.3 содержит 12 аппаратных снимков Tang Nano 9K и контрольные суммы каждого. Сопоставление шинного ядра с Icarus для команд 0 и 4 было ранее подтверждено в LAB-03.4 v0.3.1; на этой странице RTL-трасса не подменяется копией FPGA — для независимого сравнения загрузите исходный текстовый RTL-дамп.

Привязанный ROM: 14b85bc2…b5b8a3d. SHA-256 bitstream из журнала кампании: 62596847…f13 (не подтверждён чтением конфигурационной памяти FPGA).

Ограничения: две проверенные команды, отсутствие регистратора завершения инструкций, отсутствие аттестации FPGA SRAM и потактового совпадения. Файл, загруженный как RTL, идентифицируется пользователем, не криптографически браузером.
