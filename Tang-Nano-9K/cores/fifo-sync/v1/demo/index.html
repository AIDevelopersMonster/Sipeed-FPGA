02. Как работает handshake

Принятие записи и чтения

do_push = push_valid && push_ready; do_pop = pop_valid && pop_ready; push_ready = !full || (pop_ready && pop_valid); pop_valid = !empty;

Если FIFO полностью заполнен, но в этом же такте читается старый элемент, новую запись всё равно можно принять. Если FIFO пуст, чтение недоступно даже при одновременной записи: прямого обхода (bypass) в нашем RTL нет.

03. Соответствие RTL

Показана учебная JavaScript-модель поведения модуля cores/fifo-sync/v1/rtl/sync_fifo.v, а не исполнение Verilog в браузере. Текущий RTL содержит кольцевую память, два указателя и счётчик, синхронно обновляемые одним posedge clk.

В RTL overflow и underflow — одноклоковые признаки отклонённых запросов. Ширина счётчика: COUNT_W = $clog2(DEPTH+1). Для небольших глубин используется асинхронный просмотр головы; автоматическое размещение в BSRAM не гарантируется.

reg [WIDTH-1:0] memory[0:DEPTH-1]; reg [PW-1:0] write_ptr, read_ptr; reg [COUNT_W-1:0] count_reg; assign pop_data = empty ? 0 : memory[read_ptr];
