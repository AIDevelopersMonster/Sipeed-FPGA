02. Чем LIFO отличается от FIFO

LIFO — Last In, First Out

PUSH A → PUSH B → PUSH C POP → C POP → B POP → A

Нужен для стека состояний, возвратов, вложенных задач и некоторых алгоритмов. Не предназначен для сохранения порядка полученных байтов UART.

FIFO — First In, First Out

ENQUEUE A → ENQUEUE B → ENQUEUE C DEQUEUE → A DEQUEUE → B DEQUEUE → C

Нужен между производителем и потребителем потока: например, UART RX, последовательная обработка команд, буфер передачи UART TX.

03. Особенности нашего RTL

Определение входных условий

pop_valid = !empty; push_ready = !full || (pop_ready && pop_valid); do_push = push_valid && push_ready; do_pop = pop_valid && pop_ready;

Пустой стек не выдаёт элемент, даже если на том же такте есть запись. Переполнение и чтение из пустого стека отражаются импульсами overflow/underflow.

Четыре режима обновления

PUSH/POPДействие

1 / 0Запись в память по индексу count
0 / 1Уменьшение count, удаление TOP
1 / 1Замена старого TOP, count неизменен
