# Первый запуск Tang Nano 9K (Windows 10/11)

[← Главная](README.md) · [Дорожная карта](ROADMAP_RU.md)

**Цель:** запустить проверенную PiKoSoL v0.2.0 без компилятора и без изменения Flash. Нужны Tang Nano 9K, USB-C **кабель данных**, Chrome/Edge и по желанию HDMI-монитор. Для данного маршрута Gowin IDE не требуется.

## 1. Загрузите проверенный образ

Из [официального релиза нашего проекта](https://github.com/AIDevelopersMonster/Sipeed-FPGA/releases/tag/pikosol-v0.2.0) скачайте `picorv32_lab04_hdmi_nano9k.fs`.

В PowerShell проверьте целостность:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath "$env:USERPROFILE\Downloads\picorv32_lab04_hdmi_nano9k.fs"
```

Ожидается SHA256: `6862C034715DBF557C93C8F8AF8D8AA856CA8F4E62997660CEA9740F3EFDA356`. Если загрузка попала в иную папку — укажите её фактический путь. При несовпадении **остановитесь**.

## 2. Прошивка FPGA только в SRAM

1. Подключите плату USB-C. При необходимости подключите HDMI.
2. Откройте [WebUSB Loader](https://aidevelopersmonster.github.io/Sipeed-FPGA/lab04/web-loader/) в Chrome/Edge.
3. Выберите PiKoSoL v0.2.0 и проверенный `.fs` (либо автоматический вариант с проверкой хеша).
4. Выберите **JTAG Debugger / FT2232 канал A** и запустите программирование **SRAM**, не Flash.
5. Подтвердите успех загрузки по интерфейсу программатора, затем отдельно проверьте работу платы.

WebUSB требует совместимого USB-драйвера. При проблемах с обнаружением не изменяйте драйверы вслепую. Есть [альтернативный проверенный SRAM CLI-скрипт](01-PicoRV32/lab04/tools/program_lab04_sram.ps1), для которого нужен Gowin Programmer.

## 3. Команды PiKoSoL

Откройте [Web Serial](https://aidevelopersmonster.github.io/Sipeed-FPGA/lab04/web-control/), выберите **FT2232 USB Serial канал B**. Номер COM на каждом компьютере свой; параметры **115200 8N1**. Закройте другие терминалы, если порт занят.

```text
HELP
INFO
LED 1
LED ?
TERM
GFX
```

Ожидаются приглашение `PiKoSoL>`, ответы команд, реакция LED и режимы HDMI TERM/GFX (640×480). Если HDMI не работает — сначала проверьте UART отдельно.

## 4. Если что-то пошло не так

| Признак | Проверка |
| --- | --- |
| USB не определяется | Кабель данных, питание, USB-порт, диспетчер устройств |
| JTAG не виден WebUSB | Chrome/Edge, FT2232 канал A, доступ драйвера |
| Нет UART | Правильный FT2232 канал B, 115200 8N1, порт не занят |
| Программатор PASS, но плата не отвечает | Совпадение SHA, сброс FPGA и последовательное наблюдение |
| Нет HDMI | Выбран правильный вход, кабель, монитор, сначала проверьте UART |

**Проверенный результат относится к образу PiKoSoL v0.2.0 и стенду от 23.10.2026**, не ко всем ПК/драйверам. SRAM конфигурация теряется при отключении питания; заводскую Flash этот маршрут не записывает.
