# Tang Nano 9K — независимые исследовательские реализации

Именно здесь располагаются **частные случаи** общих направлений FPGA: свои версии RTL, ограничений, скриптов, протоколов и проверок.

- [SD-01: чтение microSD без CPU](sd-sector0/README.md) — самостоятельный снимок кода, сборка и симуляция.
- [SPI-01](../../../examples/peripherals/spi/01-mode0-byte/README.md) — сейчас общий RTL-эксперимент; самостоятельный hardware target добавляется при реальном испытании.
- [UART-01](../../../examples/peripherals/uart/01-8n1/README.md) — пока RTL-практикум без собственной FPGA-сборки.
- [HDMI-01](../../../examples/peripherals/hdmi/01-smoke/README.md) — самостоятельная историческая smoke-сборка, пока не перенесена в отдельный локальный исследовательский снимок.

Не создавать пустые обещания и не объявлять каждую ссылку собственной реализацией. Опыты развиваются независимо, допускают копии HDL/скриптов и получают собственную историю доказательств.
