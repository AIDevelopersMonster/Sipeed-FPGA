# Tang Nano 9K — каталог исследовательских исходников

Это **не каталог готовых прошивок**. Для простого запуска откройте [PiKoSoL v0.2.0](../../../README.md). Наличие Verilog не означает аппаратного PASS.

| Работа | Подтверждение и назначение |
| --- | --- |
| [SD-01 — сектор 0](sd-sector0/README.md) | Учебный RTL и исходный прототип; самостоятельная опубликованная сборка отдельно не перепроверялась |
| [SD-02 — multi-LBA](sd-multilba/README.md) | **BOARD PASS**: чтение 4 секторов, CRC16; без FAT32 и записи |
| [SD-03 — MBR/FAT32](sd-mbr-fat32/README.md) | Исследовательская лаборатория, статус по её протоколу |
| [SD-04 — directory](sd04-directory/README.md) | RTL и протоколы чтения каталога |
| [SD-05 — LBA bridge](sd05-lba-bridge/README.md) | Экспериментальный интерфейс и инструменты |
| [SD-06 — CMD24](sd06-cmd24/README.md) | **Ограниченный BOARD PASS**: одна тестовая SD, один LBA, запись и восстановление |
| [SD-07 — PiKoSoL MMIO](sd07-pikosol-mmio/README.md) | FIT-only исследование; не готовый выпуск v0.2.0 |

Дополнительно: [HOST-00](../../../experiments/host00-hello/README.md), [HOST-01](../../../experiments/host01-sector-read/README.md), [HOST-02](../../../experiments/host02-fat32/README.md) — отдельные протоколы и инструменты UART/SD/FAT32.

**Важно:** после консолидации актуальный код находится в main; устаревшие указания перейти на экспериментальную ветку исторические. Не используйте CMD24 с полезными данными и не записывайте конфигурационную Flash без проверки восстановления.
