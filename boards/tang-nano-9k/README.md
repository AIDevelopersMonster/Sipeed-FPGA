# Tang Nano 9K — физические реализации

FPGA GW1NR-9C, 27 MHz. Здесь хранятся **самодостаточные частные аппаратные исследования**, имеющие право развиваться отдельно от общих примеров и от PiKoSoL.

- [SD-01: microSDHC, сектор 0](experiments/sd-sector0/README.md) — локальный RTL, тесты, CST, SDC, Gowin/PowerShell, история подтверждения.

Принцип: общий учебный подход в `examples/`, собственная реализация на конкретной плате в `boards/`. Копирование проверенного RTL/скриптов для независимого воспроизводимого опыта допускается; фиксируется источник и версия. Другие FPGA получают собственную аппаратную приёмку.
