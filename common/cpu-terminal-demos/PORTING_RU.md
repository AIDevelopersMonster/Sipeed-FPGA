# Перенос сборника на FPGA-процессоры

**Сейчас это исходники на C; сборки для аппаратных ядер ещё не сделаны.** Порт не должен требовать изменений математических алгоритмов.

## Контракт

Сборка использует `src/demos.h` и `src/*.c`. Исключите `src/platform_stdio.c`, когда нет stdio, и напишите адаптер, реализующий `platform_putc()` и `platform_getc()`. Если есть готовый libc/semihosting с корректным UART-stdio, оставьте `platform_stdio.c`.

- **TX**: ждать флаг готовности UART и передать байт из `ch`.
- **RX**: блокирующее чтение одного байта, 0..255; -1 только если пользовательский ввод закончился.
- **CRLF**: `t_putchar('\n')` уже выводит CR+LF, не добавляйте его в драйвере.
- **ANSI**: MobaXterm/Windows Terminal принимают коды цвета; `8` в меню отключает цвет.
- **Память**: `.bss` должна быть инициализирована нулями, стек должен быть выделен. Самый большой набор статических массивов — лабиринт (несколько Кбайт).
- **Компиляция**: C90; без malloc, динамического выделения, stdio в алгоритмах и операций с плавающей точкой. `unsigned short` должен поддерживать 0..65535.

## Компиляция без ОС

При наличии **подготовленных** `crt0`, линкера, RAM, UART и команды загрузки, вместо `platform_stdio.c` использовать свой `platform_uart.c` и определение `-DDEMO_FREESTANDING`.

~~~text
cc-for-target -DDEMO_FREESTANDING -c src/main.c src/terminal.c src/mandel.c ...
cc-for-target ... platform_uart.c crt0.o -T target.ld -o demos.elf
~~~

Это **схема**, а не готовая команда для конкретной платы. У FPGA SoC адреса CSR/UART разные; перенос их «наугад» недопустим.

## Что фиксируем после аппаратного запуска

После появления меню в UART достаточно продемонстрировать 1) кадр Мандельброта, 2) шаг «Жизни» по Enter, 3) найденный путь в лабиринте, 4) CRC32 PASS. Скорость можно измерять только при наличии проверенного таймера конкретного CPU; код намеренно не печатает вымышленные MHz/FPS.
