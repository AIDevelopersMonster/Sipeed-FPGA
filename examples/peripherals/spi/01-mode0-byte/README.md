# SPI-01 — один байт, SPI Mode 0

Общий образовательный эксперимент **без RISC-V и без платы**. Использует копию Verilog RTL и собственного testbench из SD-01, чтобы независимо исследовать низкоуровневый SPI. CPU/SD-протокол в тесте отсутствует.

Из корня репозитория:

```powershell
& .\examples\peripherals\spi\01-mode0-byte\test.ps1
```

Ожидается `LAB05_SPI_BYTE_TB_PASS: 4 bytes, 32 clock pulses`.

SPI: **SCK** — такт; **MOSI** — выход мастера; **MISO** — вход мастера; **CS_n** — выбор ведомого, формируется внешним контроллером. CPOL=0, CPHA=0: SCK в покое низкий, выборка на переднем фронте. MSB first; байт = восемь импульсов.

При тестировании MISO замкнут на MOSI, передаются `00`, `FF`, `A5`, `3C`. Проверяются байты, число SCK, `busy/done` и состояние SCK в покое. Это **RTL PASS**, а не hardware PASS отдельного SPI-стенда.

[SD-01 — частная реализация SPI для настоящей SD-карты](../../../..//boards/tang-nano-9k/experiments/sd-sector0/README.md). Последовательность на SD-01: SPI mode 0 → CMD0/8/55/41/58/17 → сектор 512 байт → CRC16.
