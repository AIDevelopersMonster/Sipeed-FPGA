# SPI-01: передача байта, Mode 0

CPU и реальная плата не требуются. Запуск из корня репозитория:

```powershell
& .\examples\peripherals\spi\01-mode0-byte\test.ps1
```

Ожидается `LAB05_SPI_BYTE_TB_PASS: 4 bytes, 32 clock pulses`.

**SCK** — тактовая линия, **MOSI** — от мастера, **MISO** — к мастеру, **CS_n** — выбор ведомого (управляется верхним уровнем). Mode 0: CPOL=0, CPHA=0; SCK в покое 0, данные считываются на переднем фронте. Порядок битов MSB-first; один байт = 8 тактов.

Тест соединяет MISO=MOSI (loopback) и проверяет 00, FF, A5, 3C, число фронтов SCK и освобождение интерфейса. Контроллер работает в едином домене `clk=27 MHz`; регистрируемый SCK — внешний сигнал, не внутренний clock domain.

Реальный исходник `01-PicoRV32/lab05/rtl/lab05_spi_byte.v` **не зависит от PicoRV32**. Переносимого модуля вторая копия не создаётся. Этот тест подтверждает только RTL; физический SPI loopback отдельно не испытывался.
