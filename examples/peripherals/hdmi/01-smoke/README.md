# HDMI-01: видеосигнал с FPGA без PicoRV32

Самостоятельный HDMI smoke top рисует тестовую картинку и текст средствами Sipeed PicoTiny SVO, **без процессора**.

```powershell
# Подготовить привязанные по SHA исходники PicoTiny, если их нет:
& .\01-PicoRV32\lab04\tools\fetch_picotiny.ps1
# Собрать только видео (не CPU и не SD):
& .\examples\peripherals\hdmi\01-smoke\build-nano9k.ps1
```

Сборка из `lab04_hdmi_smoke_top.v` включает видео-тайминги, PLL, TMDS/SERDES и тестовую заставку. Для каждой платы требуются собственные пины, дифференциальные выходы, PLL и STA.

Созданный `.fs` лишь кандидат; скрипт **не прошивает SRAM и Flash**. Для новой аппаратной приёмки обязательны отчёты PnR/STA и проверка на HDMI-мониторе. Этот самостоятельный smoke-тест не равен уже подтверждённому полному PiKoSoL v0.2.0.

Исходники сохранены в `01-PicoRV32/lab04/rtl`, поставщик видео-IP — pin-версия PicoTiny. Копирование стороннего HDL в каждую лабораторную запрещено.
