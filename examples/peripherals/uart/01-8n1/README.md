# UART-01: 8N1 без процессора

Самостоятельное изучение асинхронного интерфейса. TX/RX — независимые RTL-модули, работающие без PicoRV32.

```powershell
& .\examples\peripherals\uart\01-8n1\test.ps1
```

Ожидается `UART TB PASS: transmitted 0xA5 as 8N1` и `LAB02_RX_RTL_PASS`.

Кадр UART 8N1: линия в покое `1`, стартовый бит `0`, затем 8 бит LSB-first и один стоповый бит `1`. Отдельной линии SCK нет: сторонам нужен согласованный baud rate. Передатчик проверяется на байте A5; приёмник — на 31, 3F, 00, ложный старт и framing error.

Единственные RTL-исходники: `01-PicoRV32/rtl/uart_tx_8n1.v` и `uart_rx_8n1.v`; тесты `01-PicoRV32/tests/tb_uart.v` и `tb_uart_rx.v`. Название каталога историческое: **CPU для этих тестов не используется**.

Тест RTL не является отдельной аппаратной приёмкой UART-only bitstream. Реальный UART уже подтверждался в составе PiKoSoL.
