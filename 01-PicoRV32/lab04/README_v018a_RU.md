# PiKoSoL LAB-04.3.1A / v0.1.8a — первый экранный слой

Это **начальный кодовый пакет**, не полная псевдографическая оболочка. Заменяет пёструю подложку SVO на стабильные тёмные зоны для текста и графики. Псевдографика `p`, оба объекта A/B, шесть LED, ROM, UART, CDC, PLL, OSER10 сохранены. Содержимое терминала пока прокручивается штатным svo_term — адресуемые окна и логотип это задача 04.3.1B.

## Архитектура v0.1.8B (ещё НЕ реализована)
Текстовый контроллер: символьная память 40x20 либо 64x20 BRAM; зоны HEADER/MENU/STATUS/LOG; курсор, scroll log, clear zone; MMIO mailbox команды zone,row,col,data с ready/valid и подтверждением; текстовый генератор 8x16 либо фактический встроенный шрифт; начало обновления по кадровой границе. Статус и журнал раздельны. UART воспроизводит семантику, а не обязательно расположение. Слои: тёмная подложка, graphics, text, LED HUD. Проверить ресурсы CLS и все новые CDC-пути прежде SRAM.
